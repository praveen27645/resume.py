# AI-Powered Resume Analyzer & Job Matcher

The AI-Powered Resume Analyzer & Job Matcher is an NLP-driven tool that compares a resume against a job description, computes an ATS-style match score using TF-IDF similarity, and highlights missing keywords to improve alignment.

## Features
- ATS-style similarity scoring with TF-IDF and cosine similarity
- Missing keyword extraction for targeted improvements
- Simple CLI workflow for quick analysis

## Tech Stack
- Python
- scikit-learn

## Run
```
python -u .\resume.py\resume.py
```
